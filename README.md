# ZshEnv

一个轻量的原生 macOS 环境变量管理器，直接管理 `~/.zshrc`。

应用图标源文件位于 `Resources/AppIcon.png`，macOS 图标包位于 `Resources/AppIcon.icns`。

## 功能

- 添加、编辑、启用/停用环境变量
- 左侧搜索框可按变量名（key）、变量值（value）或备注进行忽略大小写的实时搜索
- 拖拽 ZshEnv 新建的变量调整写入顺序，并自动保护变量引用关系
- 为每个变量添加备注
- 一键生成 24、32 或 48 位安全随机口令，适合 Token、Secret 等变量
- 启动时自动加载 `.zshrc` 中已有的 `export` 配置，并始终在原位置编辑
- 自动识别 `$PATH`、`${ZSH}`、命令替换等动态 Shell 表达式并使用双引号
- 只修改 `.zshrc` 中的 ZshEnv 托管区块，不触碰其他配置
- 保存前自动创建带时间戳的备份并执行 `zsh -n` 语法检查
- 保存后执行 `source ~/.zshrc`，并用 `launchctl setenv` 同步给之后启动的 GUI 应用

## 快速使用

### 安装

1. 打开 `dist/ZshEnv-1.0.0.dmg`。
2. 将 **ZshEnv** 拖入 **Applications** 文件夹。
3. 首次启动时，如果 macOS 阻止打开，请在 Finder 中右键 ZshEnv，选择“打开”，然后再次确认。

### 配置环境变量

1. 启动 ZshEnv。应用会自动读取 `~/.zshrc` 中已有的 `export` 配置。
2. 点击左上区域的 **+** 新建变量。
3. 填写变量名和值，例如变量名 `JAVA_HOME`、变量值 `/Library/Java/Home`。
4. 在“备注”中记录变量用途、来源或到期时间。
5. 可在左侧搜索框输入 key、value 或备注快速定位变量；搜索时不会改变实际保存顺序，并会暂时禁用拖拽排序。
6. ZshEnv 新建的变量可以拖动排序；从 `.zshrc` 读取的原有变量带有锁图标并保持原位置。
7. 使用开关临时停用变量；停用的变量仍会保留在应用中，但不会导出到环境。
8. 点击工具栏中的 **保存并生效**。应用会先备份并检查 `.zshrc`，检查通过后才写入。

### 生成随机口令

1. 选择需要设置 Token、Secret 或 Password 的变量。
2. 点击变量值下方的 **生成随机口令**。
3. 选择 24、32（推荐）或 48 位长度。
4. 确认生成结果后点击 **保存并生效**。

随机口令由 macOS 安全随机源生成，仅使用字母、数字、`-` 和 `_`，适合大多数终端、URL 和配置场景。

### 验证是否生效

打开一个新的终端窗口，执行：

```zsh
printenv 变量名
```

例如：

```zsh
printenv JAVA_HOME
```

已经打开的终端窗口不会被其他进程反向修改，需要在该窗口手动执行：

```zsh
source ~/.zshrc
```

## 注意事项

- ZshEnv 只适用于以 Zsh 为配置 Shell、使用 `~/.zshrc` 的 macOS 用户。
- 当前构建仅支持 Apple Silicon Mac（M1、M2、M3、M4 等），不支持 Intel Mac。
- 应用采用本地临时签名，未经过 Apple Developer ID 公证；首次打开可能需要使用右键“打开”。
- 保存时会管理 `.zshrc` 内 `# >>> ZshEnv managed variables >>>` 与 `# <<< ZshEnv managed variables <<<` 之间的内容，请不要随意删除或重复这些标记。
- 从现有 `.zshrc` 加载的变量会在原始行更新，不会迁移到托管区块，从而保留它们与 `ZSH=...`、`source`、插件初始化等语句的上下关系。
- 每次保存前都会在主目录生成 `.zshrc.zshenv-backup-日期时间` 备份。出现问题时可用备份恢复原配置。
- 如果整份 `.zshrc` 存在语法错误，应用会拒绝覆盖文件并显示错误信息，请先修复已有错误。
- 普通值使用单引号写入；包含 `$VAR`、`${VAR}`、`$(...)` 或反引号的值自动使用双引号，以保留 Shell 展开语义。编辑区会显示最终写入预览。
- 界面会显示变量引用的依赖项。若拖拽导致 `B="$A"` 被放到 `A` 之前，应用会撤销操作并阻止保存；无法确认定义来源的系统变量只提示风险。
- 如果 `.zshrc` 在应用打开后被终端或其他编辑器修改，应用会拒绝覆盖，请点击工具栏“重新加载”后再操作。
- 随机口令会以明文保存在 `.zshrc` 中。不要在多人共用账户中存放敏感凭据，也不要将包含口令的 `.zshrc`、备份文件或截图提交到 Git、网盘或公开渠道。高敏感凭据建议使用 macOS 钥匙串或专用密码管理器。
- 本仓库仅包含应用源码和示例说明，绝不包含真实 `.zshrc`、环境变量、凭据、备份或构建产物。提交和推送会通过 Gitleaks、隐私检查脚本和 Git 钩子复核；检查失败时不得提交或推送。
- `launchctl` 同步只影响之后启动的应用，无法改变已经运行的终端或 GUI 应用；必要时请重启相关应用。
- 删除 ZshEnv 应用不会自动删除 `.zshrc` 中的托管区块和变量。如需彻底清理，请先在应用中删除变量并保存，或手动编辑 `.zshrc`。
